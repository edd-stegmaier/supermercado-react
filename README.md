# Supermercado

Aplicación web de supermercado para explorar productos y gestionar un carrito de compras.

## Funcionalidades

- Explorar el catálogo y filtrar productos por categoría.
- Consultar el detalle, precio y stock de cada producto.
- Agregar productos al carrito, ajustar cantidades y revisar el total de la compra, respetando el stock disponible.
- Incorporar productos al catálogo mediante un formulario con validaciones.
- Ver ofertas, información del supermercado y datos de sus tiendas.

## Uso

Instala las dependencias e inicia el servidor de desarrollo:

```bash
npm install
npm run dev
```

Para generar una compilación de producción, ejecuta `npm run build`.
